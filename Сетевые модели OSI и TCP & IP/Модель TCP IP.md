TCP/IP - практическая модель интернета. Создана в 1970-е годы как часть проекта ARPANET. В отличие от OSL, модель TCP/IP **была сперва реализована**, а потом уже описана теоретически. **Состоит из 4 уровней**


| Уровень            | Протоколы                   | OSI   |
| ------------------ | --------------------------- | ----- |
| Прикладной         | HTTP, FTP, DNS, SSH, Telnet | 5,6,7 |
| Транспортный       | TCP, UDP                    | 4     |
| Сетевой (Internet) | IP, ICMP, ARP, IGMP         | 3     |
| Канал (Link)       | Ethernet, Wi-Fi, PPP, ARP   | 1,2   |
